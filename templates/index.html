Project Overview

This application provides an interactive platform for analysing UK Government Debt, Bond Markets and Wealth Transfer using historical economic data, Agent-Based Simulation, Monte Carlo Simulation and Network Analysis. Users can investigate different economic scenarios, evaluate uncertainty and explore interactions between Government, Banks, Investors and Households.
